# LineRace

Minecraft Java Edition 向けの、色分けされた直線レーンを走るレースゲームです。

**MineScript（Python）でコースを生成**し、**Paper + Skript でレーン登録・レース進行**を管理します。通常のプレイでは、参加者が各自のレーンに登録してスタートし、距離を競います。観戦者用の専用登録は不要です。

> **バージョン:** Skript **v0.1.1**（v0.1.0 をベースにしたテスト版）  
> **動作環境:** Minecraft Java Edition / Paper / Skript **2.16.1** / MineScript（Python）  
> **注意:** v0.1.1 は実サーバーでのロード・プレイテスト前です。対応する Minecraft・Paper・MineScript の細かなバージョンは、利用環境に合わせて確認してください。

## フォルダ構成

```text
LineRace/
├── README.md
├── minescript/
│   └── line_base.py       # コース生成（MineScript / Python）
└── skript/
    ├── core.sk            # 初期化・共通クリア
    ├── command.sk         # /line・/lineclear・GUI表示
    ├── gui.sk             # 管理GUIの操作
    ├── register.sk        # 石ボタンでのレーン登録
    ├── game.sk            # 距離計算・レーン判定・表示
    ├── timer.sk           # カウントダウン・制限時間・終了
    ├── respawn.sk         # 死亡・リスポーン
    └── event.sk           # 破壊・参加・退出イベント
```

## 主な機能

- **1～10レーン対応**。レーン数は Python の `LINE_COUNT` で設定（初期値5）。10色の羊毛レーンを使用。
- コースは **Zプラス方向に2,000ブロック**（Python の `TOTAL_LENGTH` で設定）。地形に沿って生成。
- レーンごとの色付きコンクリートと石ボタンで参加登録。**サバイバルモードのみ登録可能**。
- 登録時にプレイヤーごとのスタート位置・リスポーン地点を設定。
- **3 → 2 → 1 → GO** で開始。GO時に昼、設定時間の半分で夜へ変更。
- 制限時間は **5分・15分・30分**から選択。
- レース中に死亡した場合、各自のレーンのスタート位置へ戻る。終了時も同様。
- 距離表示、順位・スコアボード、BossBar、DEBUG表示。
- **SET** は前回のレース情報をクリアして登録を開始。**CLEAR** はクリアのみ。
- 停止中の距離計算・スコアボード更新などを抑制。登録していない観戦者は距離判定の対象外。

## 導入

### 1. MineScript（コース生成）

1. MineScript を導入し、`minescript/line_base.py` を Minecraft の `minescript/` ディレクトリへ配置します。
2. 必要に応じてスクリプト先頭の `LINE_COUNT`（1～10、初期値5）と `TOTAL_LENGTH`（初期値2000）を変更します。
3. ゲーム内でコースの起点に移動し、MineScript のコマンドで `line_base set` を実行します（一般的な MineScript の呼び出し例: `\line_base set`。導入環境のコマンド形式に従ってください）。
4. コースの生成完了を待ちます。

**注意:** この Python 版は `set` 専用です。実行すると新しいコース生成として内部の進捗情報を初期化しますが、**過去に生成したワールド内のブロックを自動撤去するものではありません**。コース生成は負荷がかかるため、レース参加者がいないときの実行を推奨します。

### 2. Skript（ゲーム管理）

1. Paper サーバーへ Skript 2.16.1 を導入します。
2. リポジトリの `skript/` にある **8個の `.sk` ファイル**を `plugins/Skript/scripts/linerace/` にコピーします。
3. **旧版の単一 `.sk` や古い分割版は無効化**し、イベント・コマンドの二重登録を防ぎます。
4. サーバーで `/sk reload linerace` を実行し、エラーがないか確認します。
5. 管理者が `/line` で管理GUIを開きます。

## 基本的な遊び方

1. **SET SPAWN**：管理者の現在位置をワールドスポーンに設定し、集合地点として保存。
2. **TP ALL**：必要に応じて、オンラインの全員を集合地点に移動。
3. **SET**：前のレース情報をクリアし、レーン登録受付を開始。
4. **登録**：参加者はサバイバルモードで各レーンの石ボタンを押す。登録時にそのレーンのスタート地点と個別リスポーン地点が設定される。
5. **TIME**：5分・15分・30分から制限時間を選択。
6. **START**：登録者を各自のスタートへ移動し、カウントダウン後に開始。
7. **レース**：距離を競う。死亡時は自分のレーンのスタート地点へ戻る。
8. **FINISH**：ゲーム終了後は各自のレーンのスタート地点へ戻る。
9. **次のレース**：再び **SET** を押して全員の登録をやり直す。

### 管理操作

| 操作 | 内容 |
| --- | --- |
| `/line` | 管理GUIを開く |
| `/lineclear` | レース状態・登録情報をクリア |
| `SET SPAWN` | ワールドスポーンと集合地点を設定 |
| `TP ALL` | オンラインの全員を集合地点へ移動 |
| `SET` | 初期化後、登録受付を開始 |
| `TIME` | 制限時間を選択 |
| `START` | レースを開始 |
| `STOP` | 進行中のレースを停止 |
| `CLEAR` | レース情報を初期化 |
| `STATUS` | 現在の状態を確認 |
| `DEBUG` | デバッグ表示を切り替え |

## 仕様上の注意

- **SET SPAWN はワールドスポーンも変更**します。ただし、既存プレイヤーの個別リスポーン地点がある場合、ワールドスポーンだけで復活地点が必ず変わるわけではありません。
- **SET / CLEAR** では、オンラインの登録済みプレイヤーの個別リスポーン地点を保存済みの集合地点へ戻します。**オフラインのプレイヤー**の個別リスポーン地点は残る可能性があります。
- レーン登録は参加者向けです。**観戦者は未登録のまま**観戦してください。
- 10色の羊毛について、対象ワールド・対象状態に応じてドロップを抑制します。羊毛の破壊そのものを全面禁止する機能ではありません。
- Skript の定期イベントは停止中も呼び出されますが、ゲーム状態の確認後に終了し、不要な距離判定・表示更新を行わない構成です。
- v0.1.1 は **Paper + Skript 2.16.1 の実機テスト未実施**です。最初にロードエラーを確認し、1ゲーム目と2ゲーム目の再登録・再スタートをテストしてください。
