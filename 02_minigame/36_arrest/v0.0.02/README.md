# ARREST GAME

Minecraft Paper + Skript で制作している逮捕・収監ミニゲーム。

プレイヤーがゲーム内で特定の行動をすると犯罪として判定され、
その場に牢屋を生成して収監する。

収監後は一定時間経過、または保釈金を支払うことで釈放される。

# 3. 基本システム

## 3-1. 犯罪判定

犯罪ごとに専用のスクリプトを作成する。

犯罪を検知した場合、

```text
犯罪検知
    ↓
罪状決定
    ↓
arrest_create_jail()
    ↓
牢屋生成
    ↓
プレイヤー収監
```

という流れで処理する。

---

# 4. 牢屋システム

## サイズ

```text
5 × 5
高さ 5
```

### 構造

* 床：reinforced_deepslate
* 壁：iron_bars
* 天井：reinforced_deepslate
* 看板：oak wall sign × 4

### 座標

```text
床       = プレイヤーの現在Y
プレイヤー = 床 + 1
壁        = 床 + 1 ～ 床 + 3
天井      = 床 + 4
```

---

# 5. 収監

犯罪を検知したプレイヤーを、その場に生成した牢屋へ移動させる。

収監時には、

* 罪状
* 収監時間
* 保釈金

をプレイヤーへ表示する。

また、全プレイヤーへ逮捕メッセージを表示する。

---

# 6. 逮捕タイトル

逮捕時には画面中央にタイトルを表示する。

```text
逮捕
環境破壊罪
```

罪状によってサブタイトルを変更する。

---

# 7. BossBar

収監中はBossBarを表示する。

表示例：

```text
crocadooo：環境破壊罪
```

### 仕様

* 赤色
* progress表示
* 残り時間に応じてゲージ減少
* 牢屋から一定距離以内のプレイヤーに表示
* 収監時間終了時に自動釈放

BossBarは牢屋ごとに管理する。

---

# 8. 保釈

牢屋の四方向に保釈看板を設置する。

```text
┌─────────┐
│         │
│  PLAYER │
│         │
└─────────┘
  看板 看板
```

四方向のいずれかの看板を右クリックすることで保釈を試みる。

必要なアイテムを所持している場合、

```text
保釈金を支払う
    ↓
収監解除
    ↓
牢屋撤去
```

となる。

---

# 9. 犯罪ごとの収監設定

犯罪ごとに、

* 罪状
* 収監時間
* 保釈アイテム
* 保釈個数
* 保釈金表示名

を個別に設定できる。

共通関数：

```skript
arrest_create_jail(
    player,
    reason,
    jailtime,
    bailitem,
    bailamount,
    bailname
)
```

# 10. 現在実装済みの犯罪

## 環境破壊罪

対象：

* 短い草
* 背の高い草

草を壊すと逮捕。

### 設定

```text
罪状：環境破壊罪
収監：30秒
保釈：銅インゴット × 5
```

---

## 不法投棄罪

アイテムを地面へ捨てると逮捕。

### 設定

```text
罪状：不法投棄罪
収監：30秒
保釈：銅インゴット × 3
```

---

## ボート無免許罪

ボートに乗ると逮捕。

### 設定

```text
罪状：ボート無免許罪
収監：60秒
保釈：金インゴット × 2
```

---

# 11. 収監中の判定

収監中のプレイヤーには、

```skript
{arrest::player::%uuid of player%::jail}
```

を設定する。

各犯罪スクリプトでは、この変数を確認し、

```text
すでに収監中
    ↓
新しい犯罪判定を行わない
```

という仕組みにする。

---

# 12. 牢屋の破壊防止

収監中の牢屋について、

* iron_bars
* reinforced_deepslate
* 保釈看板

の破壊を禁止する。

牢屋に関係するブロックを破壊しようとした場合、

```text
cancel event
```

として破壊を防止する。

---

# 13. 釈放

収監時間が0になる、または保釈金を支払うと釈放。

釈放時には、

* BossBar削除
* 保釈看板撤去
* 四方の鉄格子撤去
* 天井撤去
* 収監状態解除
* 釈放タイトル表示

を行う。

プレイヤーは牢屋から別の場所へTPせず、
**その場に残す**。

---

# 14. 釈放後の床

釈放時、牢屋の床5×5を

```text
cobblestone
```

へ変更する。

そのため、釈放後は、

```text
┌─────────┐
│         │
│ PLAYER  │
│         │
└─────────┘

███████████
cobblestone
```

という状態になる。

牢屋内部を一括してairにする処理は使用しない。

これにより、牢屋生成時に周囲の地形を巻き込んで消してしまうことを防ぐ。

# 17. 開発方針

ARREST GAMEは、機能を一気に複雑化させず、

```text
犯罪判定
↓
収監
↓
牢屋
↓
保釈
↓
釈放
```

という基本システムを安定させた上で、犯罪や特殊ルールを追加していく。

各機能は可能な限りファイルを分割し、
犯罪ごとの処理と牢屋本体の処理を分離する。
