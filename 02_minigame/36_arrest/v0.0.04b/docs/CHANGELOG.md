## Versioning Policy

バージョンはGit tagで管理する。

```text
v0.0.01
v0.0.02
v0.0.03
v0.0.04
v0.0.04a
v0.0.04b
```

各タグは、その時点のコードとドキュメントの状態を保存する。

v0.0.04b以降は、重大な仕様変更がない限り現在の完成形を基準として維持する。
