# ARREST GAME - Test Guide

## 1. Startup

- [ ] Paper起動
- [ ] Skript読み込み成功
- [ ] エラーがない
- [ ] ARREST GAMEがOFFで開始されても問題ない

---

## 2. ON/OFF

### ON

```text
/arrest on
```

- [ ] ONになる
- [ ] 対象ワールドが設定される
- [ ] 犯罪判定が開始される

### OFF

```text
/arrest off
```

- [ ] OFFになる
- [ ] 犯罪判定が停止する

### Status

```text
/arrest status
```

- [ ] 状態を確認できる

---

## 3. Arrest

### Grass

- [ ] Survival
- [ ] 対象ワールド
- [ ] 草を破壊
- [ ] 逮捕される
- [ ] 罪状が表示される
- [ ] 牢屋が生成される
- [ ] BossBarが表示される

### Flower

- [ ] 花を踏む
- [ ] 逮捕される

### Idle

- [ ] 30秒間移動しない
- [ ] 逮捕される

### Drop

- [ ] アイテムを捨てる
- [ ] 逮捕される

---

## 4. Jail

- [ ] 5×5
- [ ] 高さ5
- [ ] 床が正しい
- [ ] 天井が正しい
- [ ] 鉄格子が正しい
- [ ] 四方向に看板
- [ ] 牢屋を壊せない

---

## 5. Prisoner Protection

収監中：

- [ ] ダメージを受けない
- [ ] 耐性V
- [ ] 水中呼吸
- [ ] 火炎耐性
- [ ] 体力が減らない
- [ ] 満腹度が減らない
- [ ] 他の犯罪で再逮捕されない

---

## 6. Bail

- [ ] 鉄インゴット5個で保釈できる
- [ ] 鉄インゴットが消費される
- [ ] 保釈できない場合に消費されない
- [ ] BossBarが消える
- [ ] 牢屋が撤去される
- [ ] プレイヤー保護が解除される

---

## 7. Sentence

- [ ] 180秒のカウント
- [ ] BossBarが更新される
- [ ] 0秒で解放される

---

## 8. Restart

- [ ] サーバー停止
- [ ] サーバー再起動
- [ ] 古いBossBarが残らない
- [ ] `/arrest on` で再稼働できる
