うん、その段階に入るのがかなり良いです。今の v0.2.09 は「動作確認版」として残して、次は**仕組みを分離する版**にした方が後で罪状を増やしやすいです。

### まず構成はこうするのがおすすめ

```text
arrest/
├── arrest_core.sk        # 共通処理・逮捕・収監・保釈
├── arrest_jail.sk        # 牢屋生成・撤去・看板
├── arrest_bossbar.sk     # BossBar
├── arrest_config.sk      # ON/OFF・各種設定
│
└── crimes/
    ├── crime_grass.sk    # 環境破壊罪
    ├── crime_idle.sk     # サボり罪
    ├── crime_drop.sk     # 不法投棄罪
    └── crime_mob.sk      # なんかかわいそう罪
```

ただし、**最初から細かく分けすぎない**方がいいです。

最初は、

```text
arrest_config.sk
arrest_core.sk
arrest_crime_grass.sk
```

の3つくらいから始めて、牢屋・BossBarが固まったら分離するのが安全です。

## 罪状のON/OFF

これはかなり簡単にできます。

例えば `arrest_config.sk` に、

```skript
options:

    # ========================================================
    # 罪状 ON / OFF
    # ========================================================

    crime-grass: true
    crime-idle: false
    crime-drop: false
    crime-mob: false
```

としておいて、

`crime_grass.sk` では、

```skript
on break:

    if {@crime-grass} is not true:
        stop

    # 環境破壊罪の判定
```

とします。

そうすると、

```skript
crime-grass: true
```

なら有効、

```skript
crime-grass: false
```

なら完全に無効。

後から、

```skript
crime-idle: true
crime-drop: true
```

と増やしていけます。

これは今後かなり便利です。

# そして「牢屋が重なる」問題

ここは**今のうちに設計しておいた方がいいです。**

現在は、

```text
{arrest.jail.x1}
{arrest.jail.x2}
{arrest.jail.z1}
{arrest.jail.z2}
```

のように**牢屋が1個しか存在しない前提**です。

複数人が同時に捕まるようになると、

```text
プレイヤーA → 牢屋A
プレイヤーB → 牢屋B
プレイヤーC → 牢屋C
```

という管理が必要になります。

さらに、

```text
牢屋A
█████
█   █

     牢屋B
     █████
     █   █
```

のように近くに作られたり、完全に重なったりする可能性があります。

### なので将来的には

```text
{arrest.jail.1.world}
{arrest.jail.1.x1}
{arrest.jail.1.x2}
...

{arrest.jail.2.world}
{arrest.jail.2.x1}
{arrest.jail.2.x2}
...
```

のような**牢屋ID方式**にするのがいいです。

さらに、

```text
{arrest.player.jail.%player%} = 3
```

として、

> このプレイヤーは牢屋3番

と紐付けます。

そうすれば保釈時も、

```text
プレイヤー → 牢屋ID → その牢屋の座標
```

と辿れます。

# 牢屋の重なりは「生成前チェック」がいい

例えば新しい牢屋を作る前に、

```text
これから作る範囲
        ↓
X -2 ～ +2
Y 0 ～ +3
Z -2 ～ +2
```

と、

```text
既存の牢屋A
既存の牢屋B
既存の牢屋C
```

の範囲を比較します。

重なっていたら、

```text
この場所には牢屋を設置できません。
```

として逮捕処理を止める。

これが一番分かりやすいです。

**牢屋同士が重なってから解決するより、作る前に拒否する**方が圧倒的に管理しやすいです。

```text
収容中　crocadooo：環境破壊罪

```

みたいにできます。

MinecraftのBossBarのタイトルを、


現在の

```text
収監中
```

より、誰が何の罪で収容されているのかが一目で分かります。

## 「近づいたらBossBar表示」は可能

これもできます。

ただし、**BossBarそのものに「○ブロック以内なら表示」という設定があるわけではありません。**

Skript側で距離を判定します。

例えば、

```text
牢屋
   ↓
中心座標
   ↓
プレイヤーが30ブロック以内？
   ↓
YES → BossBar表示
NO  → BossBar非表示
```

という仕組みにします。

---

### 例えば30ブロック以内

```text
          プレイヤー
              ●
              │
        ← 30ブロック →
              │
         ┌────────┐
         │  牢屋   │
         └────────┘
```

近づくと、

```text
収容中　crocadooo：環境破壊罪
██████████████░░░░
```

が表示される。

離れるとBossBarが消える。

これはかなり相性がいいと思います。

# さらに複数牢屋ならBossBarも変えられる

ここが重要です。

将来的に、

```text
牢屋A
crocadooo：環境破壊罪

牢屋B
player2：不法投棄罪

牢屋C
player3：サボり罪
```

となった場合、

プレイヤーが近くにいる牢屋を探して、

```text
一番近い牢屋のBossBar
```

を表示する設計にできます。

例えば、

```text
A牢屋 ← 12m
B牢屋 ← 48m
C牢屋 ← 80m
```

ならAだけ表示。

---

## ただし、ここは一つ決めておきたい

BossBarを**誰に見せるか**です。

### A案

**牢屋の周囲にいる全員**

```text
30m以内のプレイヤー全員に表示
```

これなら「ここに誰が捕まっているか」が周囲の人にも分かります。

### B案

**収容されている本人だけ**

本人には常時、

```text
収容中　crocadooo：環境破壊罪
```

周囲の人には表示しない。

### C案

**牢屋から30m以内の人に表示**

収容者本人も含めて、

```text
牢屋の近くにいる人
↓
BossBar表示
```

これは観客・他プレイヤーにも分かりやすい仕組みです。

---

個人的には、今のARREST GAMEの方向なら**Cの「牢屋から一定距離以内」方式を前提に設計しておく**と、後々かなり面白くなりそうです。

そして今はまだ1人収容なので、まずは

```text
arrest_config.sk
        ↓
罪状ON/OFF

arrest_core.sk
        ↓
逮捕者・罪状・牢屋ID

arrest_jail.sk
        ↓
牢屋生成・撤去・保釈

arrest_bossbar.sk
        ↓
近距離表示・残り時間
```

という**複数収容を前提にした骨格**を作ってから、現在完成している「環境破壊罪」を移植するのがいいと思います。

* * *

そういう仕様なら、設計を少し変えた方がいいです。

**「牢屋は重なっても作る」＋「複数の牢屋が同時に存在する」＋「近くのプレイヤーには複数BossBarが見える」**を前提にします。

### 牢屋

例えば、

```text
牢屋A
█████
█ A █
█████

牢屋B
  █████
  █ B █
  █████
```

のように重なっていても、そのまま生成。

ただし問題は解除時です。

Aを解除するときに、

```text
牢屋Aの範囲を全部 air
```

すると、**Bの牢屋まで壊れてしまう**可能性があります。

なので、牢屋ごとに「自分が置いたブロック」を管理する必要があります。

例えば、

```text
{arrest.jail.1}
{arrest.jail.2}
{arrest.jail.3}
```

として、

```text
牢屋1
 ├ プレイヤー
 ├ 罪状
 ├ 座標
 ├ 看板座標
 └ 作成したブロック座標

牢屋2
 ├ プレイヤー
 ├ 罪状
 ├ 座標
 ├ 看板座標
 └ 作成したブロック座標
```

という管理にします。

ただし、ここはもっと単純にできて、

**「解除時に牢屋を全部消す」のではなく、牢屋の構造物を再計算して消す**

方式でもいいです。

ただ、重なった部分については、

```text
Aが置いた鉄格子
Bが置いた鉄格子
```

を区別できないので、**後から作った牢屋が先に消えると、先の牢屋の構造まで変わってしまう**という問題があります。

だから本格版では、

> **牢屋の重複を許可するが、解除時には「その牢屋が最後に置いたブロック」だけを消す**

という管理が一番安全です。

# BossBarは複数表示

これはユーザーのイメージ通りでいいと思います。

例えば、

```text
牢屋A
crocadooo：環境破壊罪

牢屋B
Steve：不法投棄罪
```

が近くにある場合、

プレイヤーには、

```text
収容中　crocadooo：環境破壊罪
██████████████░░░░


収容中　Steve：不法投棄罪
███████░░░░░░░░░░░
```

のように**2本のBossBarを同時表示**。

さらに3つ近ければ3本。

---

## 仕組み

BossBar自体を1個だけ

```text
arrest:jail
```

として使い回すのではなく、

```text
arrest:jail_1
arrest:jail_2
arrest:jail_3
...
```

と**牢屋ごとにBossBarを1個持つ**ようにします。

そして毎秒、

```text
全プレイヤー
    ↓
全牢屋を確認
    ↓
牢屋から30ブロック以内？
    ↓
YES → その牢屋のBossBarを表示
NO  → その牢屋のBossBarを非表示
```

とする。

---

### 例えば

```text
        A牢屋
       15ブロック
          ↓
       PLAYER
          ↑
       20ブロック
          ↑
        B牢屋

        C牢屋
       60ブロック
```

なら、そのプレイヤーには

```text
AのBossBar
BのBossBar
```

だけ表示。

Cは表示しない。

別のプレイヤーがCの近くに行けば、

```text
CのBossBar
```

が表示される。

そして罪状側は、

```text

arrest_crime_drop.sk

```

として、**罪状が「逮捕してください」とcoreに渡すだけ**にすると綺麗です。

この構造なら、今完成している環境破壊罪を壊さずに、まず**「複数人同時収監」対応の土台**を作れます。

うん、**かなりアリ**だと思う。しかも今回のARREST GAMEなら、設計としてはむしろシンプルになる。

### 重さについて

牢屋が **5×5×5程度**なら、壊された瞬間に直す方式はそれほど重くない。

例えば、

```text
プレイヤーが鉄格子を1個壊す
        ↓
block break を検知
        ↓
そのブロックが「収監中の牢屋」に属するか確認
        ↓
該当するなら即座に元へ戻す
```

という処理。

**常時牢屋を監視する必要はない**ので、

```text
毎秒5×5×5をチェック
```

みたいな方式よりずっと軽い。

---

### さらに今回の設計と相性がいい

複数牢屋を作るなら、各牢屋について

```text
牢屋ID
├─ 収監者
├─ 罪状
├─ ワールド
├─ 範囲
├─ 牢屋を構成するブロック
├─ 看板位置
├─ 開始時刻
└─ BossBar
```

を持たせる。

そして `on break:` で、

```text
壊されたブロック
    ↓
牢屋1の範囲？
    ↓
牢屋2の範囲？
    ↓
牢屋3の範囲？
```

と調べて、該当したら

```skript
cancel event
```

して、その場を牢屋の本来のブロックに戻す。

実際には**壊す前にキャンセルしてしまえば、復元処理すら不要**。

```text
鉄格子を壊そうとする
        ↓
ARREST牢屋のブロック？
        ↓ YES
    cancel event
        ↓
壊れない
```

これが一番軽い。

---

### ただし「牢屋以外のブロック」との区別が重要

ここは以前話していた**牢屋の重複**にも関係する。

例えば、

```text
牢屋A        牢屋B
█████       █████
█   █       █   █
█   █████████   █
█             █
█████       █████
```

のように重なった場合、

「この座標は牢屋Aのもの」
「この座標は牢屋Bのもの」

を管理しておく必要がある。

なので私は、

### 牢屋を「範囲」だけで管理するより、ブロック単位で登録

をおすすめする。

例えば概念的には、

```text
{arrest.jail.1.blocks::*}
{arrest.jail.2.blocks::*}
{arrest.jail.3.blocks::*}
```

に、

```text
world,x,y,z → reinforced_deepslate
world,x,y,z → iron_bars
```

などを登録する。

すると、

```text
on break:
    壊されたブロックの座標
    ↓
    収監中の牢屋ブロックとして登録されている？
    ↓
    YES → cancel event
```

で済む。

---

### 私ならこうする

今回のARREST GAMEでは、

**「壊されたら直す」より「壊せない」方式**にする。

ただし、

* 牢屋内のブロック
* 牢屋の天井
* 牢屋の床
* 牢屋の鉄格子
* 牢屋の看板

だけを保護する。

そして、

**牢屋が消滅・釈放された瞬間に、その保護登録も消す。**

そうすると、

```text
収監
 ↓
牢屋生成
 ↓
牢屋ブロックを登録
 ↓
収監中は破壊不可
 ↓
時間切れ / 保釈
 ↓
牢屋撤去
 ↓
ブロック登録解除
```

となる。

これなら**常時スキャンする処理がないので、かなり軽い設計**にできる。

そして複数牢屋・重複牢屋・複数BossBarを作るなら、この「**牢屋IDごとのブロック登録**」を最初から採用しておくと、後々かなり楽になる。

* * *

うん、**ちゃんとできる**。ただし「重なった牢屋を完全に安全に撤去する」部分だけ、少し設計が複雑になる。

でも、ARREST GAMEなら私はむしろ、そこを**ゲーム仕様として簡略化**するのもアリだと思う。

### 例えば3段階

**① 普通の牢屋**

```text
牢屋Aを作る
↓
牢屋Aのブロックを登録
↓
収監中は破壊不可
↓
釈放 → 牢屋Aを撤去
```

これは簡単。

**② 牢屋が重なった場合**

```text
牢屋A
█████
█   █

    牢屋B
    █████
    █   █
```

ここでは、

```text
このブロックはAにもBにも属している
```

と記録しておけば対応できる。

Aが先に釈放されても、

```text
Aを削除
↓
Bが使っているブロックは残す
```

とできる。

さらにBが釈放されたら、

```text
Bを削除
↓
Bだけが所有していた部分を撤去
```

という処理にできる。

### ただ、もっと簡単なルールもあり

「重なった牢屋については、**後から作った牢屋が優先される**」というルールにする。

例えば、

```text
牢屋A
 ↓
牢屋Bが重なる
 ↓
その部分はBが管理
```

そしてAが釈放されても、

```text
Aの撤去
↓
Bの部分は残す
```

とする。

これならかなり実装しやすい。

---

### 「監視の目をかいくぐった」はどう？

これも**ゲームとしては面白い**と思う。

例えば牢屋の破壊について、

```text
通常
鉄格子を壊す
↓
即座に修復
↓
「牢屋破壊を検知しました」
```

だけど、極低確率で

```text
鉄格子を壊す
↓
監視判定に引っかからない
↓
「……」
↓
そのまま穴が残る
```

という仕様。

ただし、これは**重なり対策として使う必要はない**と思う。

---

私ならARREST GAMEでは、

> **牢屋の重なりは普通に対応する。ただし、重なった部分は「後から作った牢屋が優先」**

にする。

そして、

> **破壊は基本的に即キャンセル。ごく一部の特殊なケースだけ「監視をかいくぐった」というゲーム要素にする**

という設計にする。

これなら「牢屋が壊れてゲームが破綻した」という事故を防ぎつつ、**監視をかいくぐるという遊びも後から追加できる**。

* * *

うん、**その進め方が一番スムーズ**だと思う。

今は重なりを完全対応しようとせず、

```text
① 普通の牢屋を複数作れる
        ↓
② 牢屋ごとに収監者・罪状・時間を管理
        ↓
③ 牢屋ごとにBossBar
        ↓
④ 牢屋のブロックは破壊不可
        ↓
⑤ 釈放・時間切れで撤去
```

までをまず完成させる。

### 後から重なり対応できる？

**できる。しかも、最初から少しだけ「変更しやすい構造」にしておけばかなり楽。**

例えば最初は、

```text
{arrest.jail.1.*}
{arrest.jail.2.*}
{arrest.jail.3.*}
```

のように**牢屋ID単位**で管理しておく。

牢屋1なら、

```text
{arrest.jail.1.world}
{arrest.jail.1.player}
{arrest.jail.1.reason}
{arrest.jail.1.x1}
{arrest.jail.1.x2}
...
```

という感じ。

この形なら、最初は単純に

```text
牢屋1を撤去
↓
牢屋1の範囲を空気にする
```

でいい。

後から重なり対応するときだけ、

```text
牢屋1を撤去
↓
そのブロックは牢屋2も使用している？
↓ YES
残す
↓ NO
撤去
```

という判定を**撤去処理に追加**すればいい。

---

### 逆に避けたい作り

最初から、

```text
{arrest.jail.x1}
{arrest.jail.x2}
{arrest.jail.player}
```

みたいに**「現在の牢屋は1個だけ」**という作りにしてしまうこと。

これだと後から複数牢屋にする際に、かなり作り直すことになる。

---

なので今回のARREST GAMEは、

> **機能は今まで通りシンプルに作る。ただしデータだけは「牢屋ID」を持たせる。**

これがちょうどいい。

そうすれば今は**普通の牢屋だけを確実に完成**させて、後から

* 複数同時収監
* 複数BossBar
* 牢屋の重なり
* 重なった部分の保護
* 牢屋ごとの撤去

# ③ `arrest_jail.sk`

ここが牢屋本体。

**牢屋IDを1、2、3……と個別に持つ**ので、複数人を同時収監できる。

```skript
# ============================================================
# ARREST GAME
# File : arrest_jail.sk
# Version : v0.0.01
#
# 牢屋生成・収監・保釈・時間終了・牢屋保護
# ============================================================


# ============================================================
# 牢屋生成
#
# 引数
# p      = 収監対象プレイヤー
# reason = 罪状
# ============================================================

function arrest_create_jail(p: player, reason: text):

    # --------------------------------------------------------
    # すでに収監中なら何もしない
    # --------------------------------------------------------

    if {arrest::player::%uuid of {_p}%::jail} is set:
        stop


    # --------------------------------------------------------
    # 牢屋IDを探す
    #
    # 1 → 2 → 3 → ...
    # 使用中の番号は飛ばす
    # --------------------------------------------------------

    set {_id} to 1

    while {arrest::jail::%{_id}%::active} is true:
        add 1 to {_id}


    # --------------------------------------------------------
    # 牢屋基本情報
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::active} to true
    set {arrest::jail::%{_id}%::player} to {_p}
    set {arrest::jail::%{_id}%::player-name} to name of {_p}
    set {arrest::jail::%{_id}%::reason} to {_reason}
    set {arrest::jail::%{_id}%::world} to world of {_p}

    add {_id} to {arrest::jail::ids::*}


    # --------------------------------------------------------
    # 牢屋位置
    #
    # プレイヤーが立っているブロックを土台にする
    # --------------------------------------------------------

    set {_floor} to floor(y-coordinate of {_p})

    set {_x} to floor(x-coordinate of {_p})
    set {_z} to floor(z-coordinate of {_p})

    set {_x1} to {_x} - 2
    set {_x2} to {_x} + 2

    set {_z1} to {_z} - 2
    set {_z2} to {_z} + 2

    # プレイヤーが立つ高さ
    set {_playerY} to {_floor} + 1

    # 鉄格子の最上段
    set {_wall-top} to {_playerY} + 2

    # 天井
    set {_ceiling} to {_playerY} + 3


    # --------------------------------------------------------
    # 保存
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::floor} to {_floor}
    set {arrest::jail::%{_id}%::x} to {_x}
    set {arrest::jail::%{_id}%::z} to {_z}

    set {arrest::jail::%{_id}%::x1} to {_x1}
    set {arrest::jail::%{_id}%::x2} to {_x2}

    set {arrest::jail::%{_id}%::z1} to {_z1}
    set {arrest::jail::%{_id}%::z2} to {_z2}

    set {arrest::jail::%{_id}%::playerY} to {_playerY}
    set {arrest::jail::%{_id}%::wall-top} to {_wall-top}
    set {arrest::jail::%{_id}%::ceiling} to {_ceiling}

    # BossBarの距離判定用
    set {arrest::jail::%{_id}%::center} to location of {_p}


    # --------------------------------------------------------
    # 残り時間
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::remaining} to {@jail-seconds}


    # ========================================================
    # 牢屋生成
    # ========================================================

    # 内部
    make {_p} execute command "/fill %{_x1}% %{_playerY}% %{_z1}% %{_x2}% %{_wall-top}% %{_z2}% air"

    # 床
    make {_p} execute command "/fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_floor}% %{_z2}% reinforced_deepslate"

    # 天井
    make {_p} execute command "/fill %{_x1}% %{_ceiling}% %{_z1}% %{_x2}% %{_ceiling}% %{_z2}% reinforced_deepslate"

    # 北
    make {_p} execute command "/fill %{_x1}% %{_playerY}% %{_z1}% %{_x2}% %{_wall-top}% %{_z1}% iron_bars"

    # 南
    make {_p} execute command "/fill %{_x1}% %{_playerY}% %{_z2}% %{_x2}% %{_wall-top}% %{_z2}% iron_bars"

    # 西
    make {_p} execute command "/fill %{_x1}% %{_playerY}% %{_z1}% %{_x1}% %{_wall-top}% %{_z2}% iron_bars"

    # 東
    make {_p} execute command "/fill %{_x2}% %{_playerY}% %{_z1}% %{_x2}% %{_wall-top}% %{_z2}% iron_bars"


    # --------------------------------------------------------
    # 看板座標
    # --------------------------------------------------------

    set {_north-sign-x} to {_x}
    set {_north-sign-y} to {_floor}
    set {_north-sign-z} to {_z1} - 1

    set {_south-sign-x} to {_x}
    set {_south-sign-y} to {_floor}
    set {_south-sign-z} to {_z2} + 1

    set {_west-sign-x} to {_x1} - 1
    set {_west-sign-y} to {_floor}
    set {_west-sign-z} to {_z}

    set {_east-sign-x} to {_x2} + 1
    set {_east-sign-y} to {_floor}
    set {_east-sign-z} to {_z}


    # --------------------------------------------------------
    # 看板保存
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::sign::north} to location({_north-sign-x}, {_north-sign-y}, {_north-sign-z}, world of {_p})
    set {arrest::jail::%{_id}%::sign::south} to location({_south-sign-x}, {_south-sign-y}, {_south-sign-z}, world of {_p})
    set {arrest::jail::%{_id}%::sign::west} to location({_west-sign-x}, {_west-sign-y}, {_west-sign-z}, world of {_p})
    set {arrest::jail::%{_id}%::sign::east} to location({_east-sign-x}, {_east-sign-y}, {_east-sign-z}, world of {_p})


    # --------------------------------------------------------
    # 看板設置
    # --------------------------------------------------------

    make {_p} execute command "/setblock %{_north-sign-x}% %{_north-sign-y}% %{_north-sign-z}% oak_wall_sign[facing=north]"
    make {_p} execute command "/setblock %{_south-sign-x}% %{_south-sign-y}% %{_south-sign-z}% oak_wall_sign[facing=south]"
    make {_p} execute command "/setblock %{_west-sign-x}% %{_west-sign-y}% %{_west-sign-z}% oak_wall_sign[facing=west]"
    make {_p} execute command "/setblock %{_east-sign-x}% %{_east-sign-y}% %{_east-sign-z}% oak_wall_sign[facing=east]"


    # --------------------------------------------------------
    # 看板文字
    # --------------------------------------------------------

    set line 2 of block at location({_north-sign-x}, {_north-sign-y}, {_north-sign-z}, world of {_p}) to "&e&l保釈金"
    set line 3 of block at location({_north-sign-x}, {_north-sign-y}, {_north-sign-z}, world of {_p}) to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at location({_south-sign-x}, {_south-sign-y}, {_south-sign-z}, world of {_p}) to "&e&l保釈金"
    set line 3 of block at location({_south-sign-x}, {_south-sign-y}, {_south-sign-z}, world of {_p}) to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at location({_west-sign-x}, {_west-sign-y}, {_west-sign-z}, world of {_p}) to "&e&l保釈金"
    set line 3 of block at location({_west-sign-x}, {_west-sign-y}, {_west-sign-z}, world of {_p}) to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at location({_east-sign-x}, {_east-sign-y}, {_east-sign-z}, world of {_p}) to "&e&l保釈金"
    set line 3 of block at location({_east-sign-x}, {_east-sign-y}, {_east-sign-z}, world of {_p}) to "&f&l鉄インゴット × {@bail-amount}"


    # --------------------------------------------------------
    # プレイヤーを牢屋中央へ
    # --------------------------------------------------------

    teleport {_p} to location({_x} + 0.5, {_playerY}, {_z} + 0.5, world of {_p})


    # --------------------------------------------------------
    # プレイヤー → 牢屋ID
    # --------------------------------------------------------

    set {arrest::player::%uuid of {_p}%::jail} to {_id}


    # --------------------------------------------------------
    # チャット
    # --------------------------------------------------------

    broadcast "&c%{_p}%が%{_reason}%で捕まりました。"


# ============================================================
# 牢屋解除
# ============================================================

function arrest_release(id: number, executor: player):

    if {arrest::jail::%{_id}%::active} is not true:
        stop


    set {_p} to {arrest::jail::%{_id}%::player}
    set {_name} to {arrest::jail::%{_id}%::player-name}
    set {_reason} to {arrest::jail::%{_id}%::reason}


    set {_floor} to {arrest::jail::%{_id}%::floor}
    set {_x1} to {arrest::jail::%{_id}%::x1}
    set {_x2} to {arrest::jail::%{_id}%::x2}
    set {_z1} to {arrest::jail::%{_id}%::z1}
    set {_z2} to {arrest::jail::%{_id}%::z2}
    set {_ceiling} to {arrest::jail::%{_id}%::ceiling}


    # --------------------------------------------------------
    # 看板を先に削除
    # --------------------------------------------------------

    make {_executor} execute command "setblock %{_x1}% %{_floor}% %{_z1}% air"
    make {_executor} execute command "setblock %{_x2}% %{_floor}% %{_z1}% air"
    make {_executor} execute command "setblock %{_x1}% %{_floor}% %{_z2}% air"
    make {_executor} execute command "setblock %{_x2}% %{_floor}% %{_z2}% air"


    # --------------------------------------------------------
    # 牢屋撤去
    # --------------------------------------------------------

    make {_executor} execute command "fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_ceiling}% %{_z2}% air"


    # --------------------------------------------------------
    # 5×5の石床を残す
    # --------------------------------------------------------

    make {_executor} execute command "fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_floor}% %{_z2}% stone"

    # BossBar削除
    # --------------------------------------------------------

    set {_key} to "arrest:jail_%{_id}%"

    execute console command "bossbar remove %{_key}%"


    # --------------------------------------------------------
    # プレイヤー側データ削除
    # --------------------------------------------------------

    if {_p} is set:
        delete {arrest::player::%uuid of {_p}%::jail}

    # 牢屋IDを一覧から削除
    remove {_id} from {arrest::jail::ids::*}


    # --------------------------------------------------------
    # メッセージ
    # --------------------------------------------------------

    broadcast "&a%{_name}%の収監期間が終了しました。"


    # --------------------------------------------------------
    # 牢屋データ削除
    # --------------------------------------------------------

    delete {arrest::jail::%{_id}%::*}


# ============================================================
# 牢屋タイマー
# ============================================================

every 1 second:

    set {_ids::*} to {arrest::jail::ids::*}

    loop {_ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is true:

            remove 1 from {arrest::jail::%{_id}%::remaining}

            if {arrest::jail::%{_id}%::remaining} <= 0:

                set {_p} to {arrest::jail::%{_id}%::player}

                if {_p} is online:
                    arrest_release({_id}, {_p})


# ============================================================
# 牢屋内のブロック破壊禁止
# ============================================================

on break:

    if {arrest::enabled} is not true:
        stop

    if world of player is not {arrest::world}:
        stop


    set {_bx} to floor(x-coordinate of event-block)
    set {_by} to floor(y-coordinate of event-block)
    set {_bz} to floor(z-coordinate of event-block)


    set {_ids::*} to {arrest::jail::ids::*}

    loop {_ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is true:

            if world of player is {arrest::jail::%{_id}%::world}:

                set {_x1} to {arrest::jail::%{_id}%::x1}
                set {_x2} to {arrest::jail::%{_id}%::x2}
                set {_floor} to {arrest::jail::%{_id}%::floor}
                set {_ceiling} to {arrest::jail::%{_id}%::ceiling}
                set {_z1} to {arrest::jail::%{_id}%::z1}
                set {_z2} to {arrest::jail::%{_id}%::z2}

                if {_bx} is between {_x1} and {_x2}:
                    if {_by} is between {_floor} and {_ceiling}:
                        if {_bz} is between {_z1} and {_z2}:

                            cancel event
                            stop


# ============================================================
# 牢屋内のブロック設置禁止
# ============================================================

on place:

    if {arrest::enabled} is not true:
        stop

    if world of player is not {arrest::world}:
        stop


    set {_bx} to floor(x-coordinate of event-block)
    set {_by} to floor(y-coordinate of event-block)
    set {_bz} to floor(z-coordinate of event-block)


    set {_ids::*} to {arrest::jail::ids::*}
```

# ④ `arrest_bossbar.sk`

ここが今回の重要部分。

**牢屋1のBossBar、牢屋2のBossBar……を完全に別管理**する。

さらに、牢屋から30ブロック以内にいるプレイヤーだけをviewerにする。

Skript 2.16系ではBossBarのviewerを直接追加・削除できるため、この方式が使える。([Skript Documentation][2])

```skript
# ============================================================
# ARREST GAME
# File : arrest_bossbar.sk
# Version : v0.0.01
#
# 牢屋ごとのBossBar管理
# ============================================================


every 1 second:

    set {_ids::*} to {arrest::jail::ids::*}

    loop {_ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is true:

            set {_name} to {arrest::jail::%{_id}%::player-name}
            set {_reason} to {arrest::jail::%{_id}%::reason}
            set {_remaining} to {arrest::jail::%{_id}%::remaining}
            set {_center} to {arrest::jail::%{_id}%::center}

            set {_key} to "arrest:jail_%{_id}%"


            # ------------------------------------------------
            # BossBar取得
            # ------------------------------------------------

            set {_bar} to boss bar with key "%{_key}%"


            # ------------------------------------------------
            # BossBarがまだ存在しない場合
            # ------------------------------------------------

            if {_bar} is not set:

                set {_bar} to a keyed red bossbar with key "%{_key}%" titled "<red>収容中　%{_name}%：%{_reason}%"

                set color of {_bar} to red
                set style of {_bar} to progress
                set progress of {_bar} to 1


            # ------------------------------------------------
            # タイトル更新
            # ------------------------------------------------

            set title of {_bar} to "<red>収容中　%{_name}%：%{_reason}%"


            # ------------------------------------------------
            # 残り時間
            # ------------------------------------------------

            set progress of {_bar} to {_remaining} / {@jail-seconds}


            # ------------------------------------------------
            # 全プレイヤーを判定
            # ------------------------------------------------

            loop all players:

                if world of loop-player is {arrest::jail::%{_id}%::world}:

                    if distance between loop-player and {_center} <= {@bossbar-radius}:

                        add loop-player to viewers of {_bar}

                    else:

                        remove loop-player from viewers of {_bar}

                else:

                    remove loop-player from viewers of {_bar}
```

これで例えば、

```text
牢屋1
crocadooo：環境破壊罪
       ↓
近くのAさん → BossBar①
近くのBさん → BossBar①
```

さらに、

```text
牢屋2
player2：環境破壊罪
       ↓
同じ場所に近い
       ↓
Aさん → BossBar① + BossBar②
Bさん → BossBar① + BossBar②
```

という状態も作れる。

```skript
            if {_sign3} is set:
                if world of clicked block is world of {_sign3}:
                    if {_cx} = floor(x-coordinate of {_sign3}):
                        if {_cy} = floor(y-coordinate of {_sign3}):
                            if {_cz} = floor(z-coordinate of {_sign3}):
                                set {_is-arrest-sign} to true


            if {_sign4} is set:
                if world of clicked block is world of {_sign4}:
                    if {_cx} = floor(x-coordinate of {_sign4}):
                        if {_cy} = floor(y-coordinate of {_sign4}):
                            if {_cz} = floor(z-coordinate of {_sign4}):
                                set {_is-arrest-sign} to true


            if {_is-arrest-sign} is not true:
                continue


            # ----------------------------------------------
            # ARREST看板だった
            # ----------------------------------------------

            cancel event


            # ----------------------------------------------
            # 保釈金確認
            # ----------------------------------------------

            if number of iron ingots in player's inventory < {@bail-amount}:

                send "&c保釈金が足りません。" to player

                stop


            # ----------------------------------------------
            # 保釈金消費
            # ----------------------------------------------

            remove {@bail-amount} iron ingots from player's inventory


            # ----------------------------------------------
            # 保釈対象
            # ----------------------------------------------

            set {_prisoner} to {arrest::jail::%{_id}%::player-name}
            set {_reason} to {arrest::jail::%{_id}%::reason}


            broadcast "&a%{_prisoner}%が%{_reason}%の保釈金によって保釈されました。"


            # ----------------------------------------------
            # 牢屋解除
            # ----------------------------------------------

            arrest_release({_id}, player)

            stop
```

# 2. `jail.sk`

ここが**牢屋システムの本体**です。

重要なのは、

```text
牢屋1
牢屋2
牢屋3
```

をそれぞれ独立して持つこと。

```text
{arrest::jail::1::...}
{arrest::jail::2::...}
{arrest::jail::3::...}
```

という構造です。

```skript
# ============================================================
# ARREST GAME
# File : jail.sk
# Version : v0.0.01
#
# 牢屋・収監・保釈・時間切れ
# ============================================================


# ============================================================
# 牢屋作成
#
# arrest_create_jail(player, "罪状")
# ============================================================

function arrest_create_jail(p: player, reason: text):

    # --------------------------------------------------------
    # すでに収監中なら終了
    # --------------------------------------------------------

    if {arrest::player::%uuid of {_p}%::jail} is set:
        stop


    # --------------------------------------------------------
    # 空いている牢屋IDを探す
    # --------------------------------------------------------

    set {_id} to 1

    while {arrest::jail::%{_id}%::active} is true:
        add 1 to {_id}


    # --------------------------------------------------------
    # 牢屋基本情報
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::active} to true
    set {arrest::jail::%{_id}%::player} to {_p}
    set {arrest::jail::%{_id}%::player-name} to name of {_p}
    set {arrest::jail::%{_id}%::uuid} to uuid of {_p}
    set {arrest::jail::%{_id}%::reason} to {_reason}
    set {arrest::jail::%{_id}%::world} to world of {_p}

    add {_id} to {arrest::jail::ids::*}


    # --------------------------------------------------------
    # 牢屋位置
    # --------------------------------------------------------

    set {_floor} to floor(y-coordinate of {_p})

    set {_x} to floor(x-coordinate of {_p})
    set {_z} to floor(z-coordinate of {_p})

    set {_x1} to {_x} - 2
    set {_x2} to {_x} + 2

    set {_z1} to {_z} - 2
    set {_z2} to {_z} + 2

    set {_player-y} to {_floor} + 1
    set {_wall-top} to {_player-y} + 2
    set {_ceiling} to {_player-y} + 3


    # --------------------------------------------------------
    # 座標保存
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::floor} to {_floor}

    set {arrest::jail::%{_id}%::x} to {_x}
    set {arrest::jail::%{_id}%::z} to {_z}

    set {arrest::jail::%{_id}%::x1} to {_x1}
    set {arrest::jail::%{_id}%::x2} to {_x2}

    set {arrest::jail::%{_id}%::z1} to {_z1}
    set {arrest::jail::%{_id}%::z2} to {_z2}

    set {arrest::jail::%{_id}%::player-y} to {_player-y}
    set {arrest::jail::%{_id}%::wall-top} to {_wall-top}
    set {arrest::jail::%{_id}%::ceiling} to {_ceiling}


    # --------------------------------------------------------
    # BossBar中心
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::center} to location({_x} + 0.5, {_player-y}, {_z} + 0.5, world of {_p})


    # --------------------------------------------------------
    # 残り時間
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::remaining} to {@jail-time}


    # ========================================================
    # 牢屋生成
    # ========================================================

    # 内部を空気にする
    make {_p} execute command "/fill %{_x1}% %{_player-y}% %{_z1}% %{_x2}% %{_wall-top}% %{_z2}% air"

    # 床
    make {_p} execute command "/fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_floor}% %{_z2}% reinforced_deepslate"

    # 天井
    make {_p} execute command "/fill %{_x1}% %{_ceiling}% %{_z1}% %{_x2}% %{_ceiling}% %{_z2}% reinforced_deepslate"

    # 北
    make {_p} execute command "/fill %{_x1}% %{_player-y}% %{_z1}% %{_x2}% %{_wall-top}% %{_z1}% iron_bars"

    # 南
    make {_p} execute command "/fill %{_x1}% %{_player-y}% %{_z2}% %{_x2}% %{_wall-top}% %{_z2}% iron_bars"

    # 西
    make {_p} execute command "/fill %{_x1}% %{_player-y}% %{_z1}% %{_x1}% %{_wall-top}% %{_z2}% iron_bars"

    # 東
    make {_p} execute command "/fill %{_x2}% %{_player-y}% %{_z1}% %{_x2}% %{_wall-top}% %{_z2}% iron_bars"


    # ========================================================
    # 看板座標
    # ========================================================

    set {_north} to location({_x}, {_floor}, {_z1} - 1, world of {_p})
    set {_south} to location({_x}, {_floor}, {_z2} + 1, world of {_p})
    set {_west} to location({_x1} - 1, {_floor}, {_z}, world of {_p})
    set {_east} to location({_x2} + 1, {_floor}, {_z}, world of {_p})

    set {arrest::jail::%{_id}%::sign::north} to {_north}
    set {arrest::jail::%{_id}%::sign::south} to {_south}
    set {arrest::jail::%{_id}%::sign::west} to {_west}
    set {arrest::jail::%{_id}%::sign::east} to {_east}


    # ========================================================
    # 看板設置
    # ========================================================

    # 先に空気にする
    set block at {_north} to air
    set block at {_south} to air
    set block at {_west} to air
    set block at {_east} to air

    # 看板
    make {_p} execute command "/setblock %{_x}% %{_floor}% %{_z1 - 1}% oak_wall_sign[facing=north]"
    make {_p} execute command "/setblock %{_x}% %{_floor}% %{_z2 + 1}% oak_wall_sign[facing=south]"
    make {_p} execute command "/setblock %{_x1 - 1}% %{_floor}% %{_z}% oak_wall_sign[facing=west]"
    make {_p} execute command "/setblock %{_x2 + 1}% %{_floor}% %{_z}% oak_wall_sign[facing=east]"


    # ========================================================
    # 看板文字
    # ========================================================

    set line 2 of block at {_north} to "&e&l保釈金"
    set line 3 of block at {_north} to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at {_south} to "&e&l保釈金"
    set line 3 of block at {_south} to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at {_west} to "&e&l保釈金"
    set line 3 of block at {_west} to "&f&l鉄インゴット × {@bail-amount}"

    set line 2 of block at {_east} to "&e&l保釈金"
    set line 3 of block at {_east} to "&f&l鉄インゴット × {@bail-amount}"


    # ========================================================
    # プレイヤーを牢屋へ
    # ========================================================

    teleport {_p} to location({_x} + 0.5, {_player-y}, {_z} + 0.5, world of {_p})


    # ========================================================
    # プレイヤー → 牢屋ID
    # ========================================================

    set {arrest::player::%uuid of {_p}%::jail} to {_id}


    # ========================================================
    # メッセージ
    # ========================================================

    send "&cあなたは &e%{_reason}% &cで逮捕されました。" to {_p}

    broadcast "&c[ARREST] &f%{_p}% &cが &e%{_reason}% &cで収監されました。"


# ============================================================
# 牢屋解除
#
# arrest_release(id, 実行プレイヤー)
# ============================================================

function arrest_release(id: number, executor: player):

    if {arrest::jail::%{_id}%::active} is not true:
        stop


    set {_p} to {arrest::jail::%{_id}%::player}
    set {_name} to {arrest::jail::%{_id}%::player-name}


    set {_floor} to {arrest::jail::%{_id}%::floor}

    set {_x1} to {arrest::jail::%{_id}%::x1}
    set {_x2} to {arrest::jail::%{_id}%::x2}

    set {_z1} to {arrest::jail::%{_id}%::z1}
    set {_z2} to {arrest::jail::%{_id}%::z2}

    set {_ceiling} to {arrest::jail::%{_id}%::ceiling}


    # --------------------------------------------------------
    # 看板を先に削除
    # --------------------------------------------------------

    set block at {arrest::jail::%{_id}%::sign::north} to air
    set block at {arrest::jail::%{_id}%::sign::south} to air
    set block at {arrest::jail::%{_id}%::sign::west} to air
    set block at {arrest::jail::%{_id}%::sign::east} to air


    # --------------------------------------------------------
    # 牢屋撤去
    # --------------------------------------------------------

    make {_executor} execute command "/fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_ceiling}% %{_z2}% air"


    # --------------------------------------------------------
    # 5×5の石床を残す
    # --------------------------------------------------------

    make {_executor} execute command "/fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_floor}% %{_z2}% stone"


    # --------------------------------------------------------
    # BossBar削除
    # --------------------------------------------------------

    execute console command "/bossbar remove arrest:jail_%{_id}%"


    # --------------------------------------------------------
    # プレイヤー情報削除
    # --------------------------------------------------------

    if {_p} is set:
        delete {arrest::player::%uuid of {_p}%::jail}


    # --------------------------------------------------------
    # ID一覧から削除
    # --------------------------------------------------------

    remove {_id} from {arrest::jail::ids::*}


    # --------------------------------------------------------
    # メッセージ
    # --------------------------------------------------------

    broadcast "&a[ARREST] &f%{_name}% &aが釈放されました。"


    # --------------------------------------------------------
    # 牢屋データ削除
    # --------------------------------------------------------

    delete {arrest::jail::%{_id}%::*}


# ============================================================
# 牢屋タイマー
# ============================================================

every 1 second:

    set {_ids::*} to {arrest::jail::ids::*}

    loop {_ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is true:

            remove 1 from {arrest::jail::%{_id}%::remaining}

            if {arrest::jail::%{_id}%::remaining} <= 0:

                set {_p} to {arrest::jail::%{_id}%::player}

                if {_p} is online:

                    arrest_release({_id}, {_p})


# ============================================================
# 牢屋内の破壊禁止
# ============================================================

on break:

    if {arrest::enabled} is not true:
        stop

        stop

    set {_y} to floor(y-coordinate of event-block)
    set {_z} to floor(z-coordinate of event-block)

                        stop


# ============================================================
# 牢屋内の設置禁止
# ============================================================

on place:

    if {arrest::enabled} is not true:
        stop

    if world of player is not {arrest::world}:
        stop
```

# 3. `bossbar.sk`

ここはSkript 2.16.1のBossBar機能を使います。

キー付きBossBarは、

```skript

```

で作成できます。viewerは `add ... to viewers` / `remove ... from viewers` で管理できます。([Skript Documentation][2])

```skript
# ============================================================
# ARREST GAME
# File : bossbar.sk
# Version : v0.0.01
#
# 牢屋ごとのBossBar
# ============================================================


every 1 second:

    loop {arrest::jail::ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is true:

            if {_bar} is not set:
```

### イメージ

プレイヤーが罪を犯す
↓
現在地を中心に、例えば**半径30ブロック**を検索
↓
「ここなら牢屋を作っても大丈夫」という場所を探す
↓

↓
そこに5×5×5の牢屋を生成
↓
プレイヤーを牢屋の中央へテレポート

```text
       │            │
       └──────────┘
              ↓

              ↓
         ┌─────────┐
         │  牢屋   │
         │         │
         │    ●    │
         │         │
         └─────────┘
```

### 「安全地帯」の条件を決められる

例えば最初は、

* 地面がある
* 牢屋の5×5範囲が空いている
* 水・溶岩ではない
* 木や建物の中ではない
* 他の牢屋から一定距離離れている
* Y座標が極端ではない

くらいで十分です。

特にSkriptには、

```skript

```

のような判定や、指定範囲のブロックをループする機能があります。([Skript Documentation][1])

なので、**「牢屋を作れる場所か？」を5×5×5単位で検査する**ことができます。

```text
④ -Z 5
```

これなら「プレイヤーが立っている場所そのもの」を壊さずに済みます。

# 3. `bossbar.sk`

ここは**全プレイヤーに対して牢屋から30ブロック以内なら表示**します。

つまり、

```text
        プレイヤーA
             ●
             │ 30m以内
             │
       ┌─────────┐
       │  牢屋    │
       │    P    │
       └─────────┘
             │
             │ 30m以内
             ●
        プレイヤーB
```

A・B・収監者それぞれに表示されます。

```skript
# ============================================================
# ARREST GAME
# File : bossbar.sk
# Version : v0.0.01
#
# BossBar管理
#
# ・牢屋ごとにBossBar
# ・牢屋から30ブロック以内の全プレイヤーに表示
# ・収監者自身にも表示
# ・複数牢屋なら複数BossBar
#
# ============================================================


every 1 second:

    if {arrest::jail::ids::*} is not set:
        stop


    loop {arrest::jail::ids::*}:

        set {_id} to loop-value

        if {arrest::jail::%{_id}%::active} is not true:
            next loop


        # ====================================================
        # データ
        # ====================================================

        set {_p} to {arrest::jail::%{_id}%::player}
        set {_name} to {arrest::jail::%{_id}%::player-name}
        set {_reason} to {arrest::jail::%{_id}%::reason}
        set {_remaining} to {arrest::jail::%{_id}%::remaining}
        set {_world} to {arrest::jail::%{_id}%::world}

        set {_x} to {arrest::jail::%{_id}%::x1} + 2.5
        set {_y} to {arrest::jail::%{_id}%::y1} + 1
        set {_z} to {arrest::jail::%{_id}%::z1} + 2.5


        # ====================================================
        # BossBarが存在しなければ作成
        # ====================================================

        execute console command "bossbar add arrest:jail_%{_id}% {""text"":""収監中　%{_name}%：%{_reason}%"",""color"":""red""}"


        # ====================================================
        # BossBar設定
        # ====================================================

        execute console command "bossbar set arrest:jail_%{_id}% max {@jail-time}"
        execute console command "bossbar set arrest:jail_%{_id}% value %{_remaining}%"
        execute console command "bossbar set arrest:jail_%{_id}% color red"
        execute console command "bossbar set arrest:jail_%{_id}% style progress"


        # ====================================================
        # 近くのプレイヤーを検索
        # ====================================================

        set {_targets} to ""

        loop all players:

            if world of loop-player is {_world}:

                set {_center} to location({_x}, {_y}, {_z}, {_world})

                if distance between loop-player and {_center} <= {@bossbar-radius}:

                    if {_targets} is "":
                        set {_targets} to "%name of loop-player%"
                    else:
                        set {_targets} to "%{_targets}% %name of loop-player%"


        # ====================================================
        # 表示対象設定
        # ====================================================

        if {_targets} is not "":

            execute console command "bossbar set arrest:jail_%{_id}% players %{_targets}%"
            execute console command "bossbar set arrest:jail_%{_id}% visible true"

        else:

            execute console command "bossbar set arrest:jail_%{_id}% visible false"
```

### BossBarについて1点

このコードでは、1秒ごとに `bossbar add` を実行していますが、**すでに存在するIDに対してaddするとエラーになる可能性があります**。

なので、実際のv0.0.1では「作成済みフラグ」を持たせた方が確実です。そこを修正した完成版はこうです。

```skript
# ============================================================
# ARREST GAME
# File : bossbar.sk
# Version : v0.0.01
```

### ただし1点だけ

`/arrest on` で**変数を削除する設計**なので、これは意図したとおり「新しいゲーム開始＝完全リセット」です。

そのため、

```text
/arrest on
```

を途中で押すと、

* 現在の収監情報
* 牢屋ID
* プレイヤーとの紐付け
* タイマー
* BossBar管理情報

は全部リセットされます。

これは今回の「ON時点で変数を削除」という方針に合わせています。

**まずはこのv0.0.1を読み込んで、環境破壊罪 → 牢屋 → 30秒 → 自動釈放 → 保釈看板 → BossBar → 複数牢屋、の順にテストするのがいいです。**

* * *

はい、**今渡した v0.0.1 は複数人対応になっています**。

例えば同時に3人捕まると、

```text
プレイヤーA → 牢屋ID 1
プレイヤーB → 牢屋ID 2
プレイヤーC → 牢屋ID 3
```

として、それぞれ別々に

```text
{arrest::jail::1::player}

{arrest::jail::3::player}
{arrest::jail::3::remaining}
```

を持ちます。


なので、AとBを個別に「どの牢屋に入っているか」管理できます。SkriptではUUIDを変数のインデックスに使ってプレイヤーごとのデータを分離する方法が正式にサポートされています。 ([GitHub][1])

さらに、

* Bはまだ20秒

という**個別の収監時間**も可能です。

BossBarも牢屋IDごとに


ただし、**1点だけ今のコードで将来的に注意したいところがあります。**

牢屋Aと牢屋Bが物理的に重なった場合、

```text

  ↓
```

後から作った牢屋の `fill` が先の牢屋を上書きする可能性があります。

で将来的に解決する部分です。

今のv0.0.1では、

**複数人 → 対応済み**
**牢屋の重なり → 未対応**

という整理でOKです。

### 重さについて

今のARREST処理はかなり軽いです。

* 逮捕された人ごとに **1秒ごとのタイマー**
* 逮捕者ごとに **BossBar 1個**
* BossBarは**半径30ブロック以内**のプレイヤーだけ更新
* 通常時は「草を壊したか」をイベントで判定
* 牢屋も必要なときだけ生成
* モブを大量に常時監視するような処理はまだない

例えば、

```text
プレイヤー10人
逮捕者3人
→ 3個の牢屋
→ 3個のBossBar
→ 3本のタイマー
```

くらいなら、**ほぼ気にしなくていいレベル**です。

さらに、

```text
プレイヤー30人
逮捕者10人
```

となっても、現在の仕組みなら処理量はそれほど大きくありません。

```text

```

3人目：


という感じなので、**「牢屋は1個」という設計ではありません。**

そのため、

```text

B → 牢屋2
```

と増やせます。

そして将来的に100人規模などを考えるなら、その時点で「常時監視系の罪状」だけ最適化すればいいです。

### 特に注意するのは2つ

**① サボり罪**

全員について、

```text
最後に動いた時間
↓
30秒経過した？
↓
まだ同じ場所？
```

を監視する必要があります。

でも、例えば**1秒に1回チェック**にすればかなり軽いです。

---

**② 凝視罪**

これは一番気を付けたいです。

例えば20人いると、

```text
A → B,C,D...
B → A,C,D...
C → A,B,D...
```

というように、プレイヤー同士の組み合わせを見ることになります。

なので、

```text
毎tick × 全員 × 全員
```

みたいな作りにはしない方がいいです。

**例えば0.5～1秒間隔で判定し、距離・視線角度・遮蔽物などで段階的に絞る**のがいいです。

**イベント型はイベントで処理**


### ARRESTの開発順

**① v0.0.01**
まず現在の基礎部分を確認。

* `/arrest on / off / status`
* ワールド限定
* 変数初期化
* 複数人収監
* 牢屋生成
* 30秒収監
* 鉄インゴット5個で釈放
* BossBar
* 牢屋の破壊・設置禁止
* 環境破壊罪

ここが問題なく動くことを確認。

↓

**② 無敵・収監中保護**

収監されたプレイヤーについて、

* ダメージを受けない
* 他プレイヤーから攻撃されない
* 空腹が減らない
* 炎・溺水などからも保護
* 牢屋内で安全に待機
* 必要ならゲームモードや移動制限も調整

という「収監状態」を完成させる。

↓

**③ 罪状を追加**

例えば、

```text
crime/
├─ grass.sk
├─ idle.sk
├─ drop.sk
├─ mob.sk
├─ boat.sk
├─ flower.sk
├─ stare.sk
├─ chest.sk
├─ gunpowder.sk
├─ sword.sk
├─ assault.sk
└─ egg.sk
```

を**1個ずつ追加してテスト**。

↓

**④ 「収監中は新しい罪を犯さない」**

これはかなり重要です。

例えばAが、

```text
環境破壊罪
↓
逮捕
↓
牢屋の中で剣を持つ
↓
銃刀法違反！
```

みたいになるのは避ける。

各罪状の最初に共通して、

```skript
if {arrest::player::%uuid of player%::jail} is set:
    stop
```

という形にしておけば、

> **収監中のプレイヤーは罪状判定の対象外**

にできます。

---

### さらに、このタイミングで「状態」を整理すると綺麗

例えば、

```text
{arrest::enabled}
{arrest::world}

{arrest::player::UUID::jail}
{arrest::player::UUID::reason}
{arrest::player::UUID::jailed}
```

というように、

**「ARRESTが稼働している」**

と

**「このプレイヤーが収監されている」**

を明確に分離しておく。

そうすると今後、

```text
通常プレイヤー
    ↓
罪を犯す
    ↓
収監
    ↓
収監中は罪状判定OFF
    ↓
釈放
    ↓
通常プレイヤーに戻る
```

という流れが非常に分かりやすくなります。

なので、今は**v0.0.01をいじりすぎず、まず現在の基礎部分を実際にテスト**するのがいいです。

その後は、

**v0.0.02 = 無敵・収監状態の完成**
**v0.0.03 = 罪状追加開始**

くらいの進め方が綺麗だと思います。

* * *

そう、それが**v0.0.02のテストとしてかなり良い**です 👍

例えば一連のテストをこうします。

1. `/arrest on`
2. 草を壊す
3. → **環境破壊罪で収監**
4. 牢屋の中で30秒待つ
5. その間に草を置く
6. その草を壊す
7. → **2回目の環境破壊罪が発生しない**
8. 牢屋の外へ釈放
9. もう一度草を壊す
10. → **再び環境破壊罪で収監**

つまり、

```text
通常
 ↓
草を壊す
 ↓
収監
 ↓
【収監中】
草を置く
草を壊す
 ↓
罪状発生しない ← ここを確認
 ↓
釈放
 ↓
草を壊す
 ↓
再収監
```

さらにv0.0.02では、同時に**無敵状態も確認**するといいです。

牢屋の中で、

* 自分でダメージを受ける
* 他プレイヤーに殴ってもらう
* 炎に入る
* 高いところから落ちる
* 水中に入る

などを試して、**収監中だけ安全になっているか**を見る。

このテストが通れば、

> **「収監されているプレイヤー」という状態がちゃんと独立して機能している**

ことを確認できます。

そしてその状態ができてから罪状を増やせば、各 `crime/*.sk` の先頭に同じ「収監中なら判定しない」という仕組みを入れるだけなので、かなり管理しやすくなります。
