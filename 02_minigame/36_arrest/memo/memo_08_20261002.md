### 作りやすさ順でいうと

| 犯罪            | 判定       | 作りやすさ | 備考               |
| ------------- | -------- | ----- | ---------------- |
| **不法投棄罪**     | アイテムを捨てた | ⭐⭐⭐⭐⭐ | `on drop` で判定できる |
| **ボート無免許罪**   | ボートに乗った  | ⭐⭐⭐⭐⭐ | 乗った瞬間を判定         |
| **暴行罪**       | プレイヤーを攻撃 | ⭐⭐⭐⭐  | `on damage` で判定  |
| **花踏み罪**      | 花の上に乗る   | ⭐⭐⭐⭐  | 移動判定が必要          |

| **なんかかわいそう罪** | 友好モブを叩く  | ⭐⭐⭐   | 対象モブの整理が必要       |
| **サボり罪**      | 30秒動かない  | ⭐⭐    | 時間・移動監視が必要       |

なので、**最初の2つなら「不法投棄罪」と「ボート無免許罪」**がかなり良いと思います。

## そして保釈金は「アイテム＋個数」にしましょう

これは鉄だけに固定しない方が、ARREST GAMEとしてかなり面白くなります。

例えば、

| 犯罪        | 収監時間 | 保釈金        |
| --------- | ---: | ---------- |
| 環境破壊罪     |  30秒 | 銅 × 5      |
| 不法投棄罪     |  30秒 | 銅 × 3      |
| 窃盗罪       |  45秒 | 鉄 × 2      |
| 暴行罪       |  60秒 | 鉄 × 5      |
| ボート無免許罪   |  60秒 | 金 × 2      |
| なんかかわいそう罪 |  60秒 | 銅 × 10     |
| 花踏み罪      |  90秒 | 鉄 × 5      |
| サボり罪      | 180秒 | ダイヤモンド × 1 |

みたいにできます。

さらに、

**「保釈金＝1種類のアイテム」とは限らない**

ようにしておくと拡張性があります。

例えば、

```text
鉄インゴット × 5
```

だけでなく、

```text
金インゴット × 3
```

や、

```text
銅インゴット × 10
```

や、

```text
ダイヤモンド × 1
```

将来的には、

```text
鉄インゴット × 5
＋
金インゴット × 2
```

のような複数種類も可能にできます。

### ここは設計をこうするのがおすすめ

牢屋側に、

```text
犯罪名
収監時間
保釈アイテム
保釈個数
```

を渡す。

例えば、

```text
arrest_create_jail(
    プレイヤー,
    "不法投棄罪",
    30,
    copper_ingot,
    3
)
```

という考え方。

そうすると `jail.sk` は、

> 「これは草の犯罪だから鉄5個」

みたいな判断を一切しません。

**「この牢屋は銅3個が保釈条件」**

という情報だけ持ちます。

これは今後、犯罪が10個、20個と増えてもかなり管理しやすいです。

### なので次の2つなら

**① 不法投棄罪**
アイテムを捨てる → その場で逮捕

**② ボート無免許罪**
ボートに乗る → その場で逮捕

この2つを追加して、

**「犯罪ごとに収監時間・保釈アイテム・保釈個数が違う」**

という新しい仕組みを一緒に作るのが良いと思います。

はい。今回は**「犯罪ごとに `犯罪名・収監時間・保釈アイテム・保釈個数` を牢屋へ渡す」**形にします。

# 1. `crime/grass.sk`

まず現在の草犯罪を、新しい共通仕様に変更します。

```skript
# ============================================================
# ARREST GAME
# File : crime/grass.sk
#
# 犯罪：環境破壊罪
# 条件：短い草・背の高い草を壊す
# ============================================================


on break of short grass or tall grass:

    # --------------------------------------------------------
    # 収監中は新たな犯罪を発生させない
    # --------------------------------------------------------

    if {arrest::jailed::%uuid of player%} is true:
        stop


    # --------------------------------------------------------
    # 犯罪判定
    # --------------------------------------------------------

    # 犯罪発生をキャンセルしない
    # → 草は通常通り壊れる


    # --------------------------------------------------------
    # 犯罪情報
    # --------------------------------------------------------

    set {_reason} to "環境破壊罪"
    set {_time} to 30
    set {_bail-item} to copper ingot
    set {_bail-amount} to 5


    # --------------------------------------------------------
    # 逮捕
    # --------------------------------------------------------

    arrest_create_jail(
        player,
        {_reason},
        {_time},
        {_bail-item},
        {_bail-amount}
    )
```

これで環境破壊罪は、

```text
収監時間：30秒
保釈金：銅インゴット × 5
```

になります。

# 4. `jail.sk`

ここが今回の一番重要な変更です。

現在の

```text
arrest_create_jail(player, reason)
```

を、

```text
arrest_create_jail(player, reason, time, bail-item, bail-amount)
```

に変更します。

つまり牢屋は、

```text
誰が？
何の罪？
何秒？
何で保釈？
何個？
```

を持つようになります。

### 重要

ここは現在の `jail.sk` 全文が手元にないため、**今のコードを勝手に再構築して上書きするのは避けます**。

現在の `jail.sk` を貼ってもらえれば、そこから、

```text
v0.0.1
↓
v0.0.2
```

として**看板・BossBar・破壊禁止・複数牢屋管理を全部維持したまま**、この新仕様に変更したフルスクリプトを作れます。

変更するポイントは以下です。

### ① function

現在：

```skript
function arrest_create_jail(p: player, reason: text):
```

変更：

```skript
function arrest_create_jail(p: player, reason: text, time: number, bailitem: item type, bailamount: number):
```

### ② 収監時間

現在の固定値：

```skript
set {arrest::jail::%{_id}%::time} to 180
set {arrest::jail::%{_id}%::max-time} to 180
```

を、

```skript
set {arrest::jail::%{_id}%::time} to {_time}
set {arrest::jail::%{_id}%::max-time} to {_time}
```

に変更。

### ③ 保釈情報を保存

```skript
set {arrest::jail::%{_id}%::bail::item} to {_bail-item}
set {arrest::jail::%{_id}%::bail::amount} to {_bail-amount}
```

### ④ 収監状態

牢屋生成時に、

```skript
set {arrest::jailed::%uuid of {_p}%} to true
```

を追加。

これによって全犯罪ファイルで、

```skript
if {arrest::jailed::%uuid of player%} is true:
    stop
```

とできるようにします。

### ⑤ 釈放時

牢屋を撤去するとき、

```skript
delete {arrest::jailed::%uuid of {_p}%}
```

として解除します。

# 5. 保釈処理

今までの、

```text
鉄インゴット5個
```

固定ではなく、牢屋に保存された情報を見るようにします。

考え方は、

```skript
set {_bail-item} to {arrest::jail::%{_id}%::bail::item}
set {_bail-amount} to {arrest::jail::%{_id}%::bail::amount}
```

そして、

```skript
if player has {_bail-amount} of {_bail-item}:
```

なら、

```skript
remove {_bail-amount} of {_bail-item} from player
```

として保釈。

看板も、

```text
保釈金
銅インゴット × 5
```

や、

```text
保釈金
金インゴット × 2
```

のように犯罪ごとに変えられます。

## `jail.sk` v0.0.02 → 新仕様版

```skript
# ============================================================
# ARREST GAME
# File : jail.sk
# Version : v0.0.02
#
# 牢屋管理
#
# ・5 x 5
# ・高さ5
# ・reinforced_deepslate
# ・iron_bars
# ・四方向に保釈看板
# ・犯罪ごとの収監時間
# ・犯罪ごとの保釈アイテム
# ・犯罪ごとの保釈個数
# ・BossBarの削除もここで実行
#
# ============================================================


# ============================================================
# 牢屋作成
#
# arrest_create_jail(player, reason, time, bail-item, bail-amount, bail-name)
#
# ============================================================

function arrest_create_jail(p: player, reason: text, jailtime: number, bailitem: item type, bailamount: number, bailname: text):

    # --------------------------------------------------------
    # 牢屋ID
    # --------------------------------------------------------

    add 1 to {arrest::jail::next-id}

    set {_id} to {arrest::jail::next-id}


    # --------------------------------------------------------
    # プレイヤー位置
    # --------------------------------------------------------

    set {_x} to floor(x-coordinate of {_p})
    set {_floor} to floor(y-coordinate of {_p})
    set {_z} to floor(z-coordinate of {_p})

    set {_world} to world of {_p}


    # --------------------------------------------------------
    # 牢屋サイズ
    #
    # X -2 ～ +2
    # Z -2 ～ +2
    #
    # 床       = Y
    # プレイヤー = Y+1
    # 壁       = Y+1 ～ Y+3
    # 天井     = Y+4
    # --------------------------------------------------------

    set {_x1} to {_x} - 2
    set {_x2} to {_x} + 2

    set {_z1} to {_z} - 2
    set {_z2} to {_z} + 2

    set {_player-y} to {_floor} + 1
    set {_wall-top} to {_floor} + 3
    set {_ceiling} to {_floor} + 4


    # --------------------------------------------------------
    # 牢屋情報保存
    # --------------------------------------------------------

    add {_id} to {arrest::jail::ids::*}

    set {arrest::jail::%{_id}%::active} to true

    set {arrest::jail::%{_id}%::player} to {_p}
    set {arrest::jail::%{_id}%::uuid} to uuid of {_p}

    set {arrest::jail::%{_id}%::reason} to {_reason}

    set {arrest::jail::%{_id}%::world} to {_world}

    set {arrest::jail::%{_id}%::x1} to {_x1}
    set {arrest::jail::%{_id}%::x2} to {_x2}

    set {arrest::jail::%{_id}%::z1} to {_z1}
    set {arrest::jail::%{_id}%::z2} to {_z2}

    set {arrest::jail::%{_id}%::floor} to {_floor}
    set {arrest::jail::%{_id}%::ceiling} to {_ceiling}


    # --------------------------------------------------------
    # 犯罪ごとの収監時間
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::time} to {_jailtime}
    set {arrest::jail::%{_id}%::max-time} to {_jailtime}


    # --------------------------------------------------------
    # 犯罪ごとの保釈情報
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::bail::item} to {_bailitem}
    set {arrest::jail::%{_id}%::bail::amount} to {_bailamount}
    set {arrest::jail::%{_id}%::bail::name} to {_bailname}


    # --------------------------------------------------------
    # プレイヤーと牢屋IDを紐付け
    # --------------------------------------------------------

    set {arrest::player::%uuid of {_p}%::jail} to {_id}


    # ========================================================
    # 牢屋生成
    # ========================================================

    # --------------------------------------------------------
    # 内部を空気
    # --------------------------------------------------------

    execute {_p} command "/fill %{_x1}% %{_player-y}% %{_z1}% %{_x2}% %{_wall-top}% %{_z2}% air"


    # --------------------------------------------------------
    # 床
    # --------------------------------------------------------

    execute {_p} command "/fill %{_x1}% %{_floor}% %{_z1}% %{_x2}% %{_floor}% %{_z2}% reinforced_deepslate"


    # --------------------------------------------------------
```

```skript
arrest_create_jail(player, "環境破壊罪", 30, copper ingot, 5, "銅インゴット")
```

と呼べば、

```text
罪状：環境破壊罪
```

になります。

```skript
arrest_create_jail(player, "ボート無免許罪", 60, gold ingot, 2, "金インゴット")
```


です。

```skript
# 牢屋解除

function arrest_release_jail(id: number):

    # --------------------------------------------------------
    # 牢屋が存在しない
    # --------------------------------------------------------

    if {arrest::jail::%{_id}%::active} is not true:
        stop

    # --------------------------------------------------------
    # プレイヤー取得
    # --------------------------------------------------------

    set {_p} to {arrest::jail::%{_id}%::player}
    set {_uuid} to {arrest::jail::%{_id}%::uuid}

    set {_world} to {arrest::jail::%{_id}%::world}

    set {_x1} to {arrest::jail::%{_id}%::x1}
    set {_x2} to {arrest::jail::%{_id}%::x2}

    set {_z1} to {arrest::jail::%{_id}%::z1}
    set {_z2} to {arrest::jail::%{_id}%::z2}

    set {_floor} to {arrest::jail::%{_id}%::floor}
    set {_ceiling} to {arrest::jail::%{_id}%::ceiling}

    # --------------------------------------------------------
    # BossBar削除
    # --------------------------------------------------------

    if {arrest::jail::%{_id}%::bossbar} is set:
        remove {arrest::jail::%{_id}%::bossbar}

    # --------------------------------------------------------
    # 看板を先に削除
    #
    # 牢屋撤去後に看板を消すと
    # 看板がアイテム化する可能性があるため
    # 必ず先に削除する
    # --------------------------------------------------------

    set {_sx} to {arrest::jail::%{_id}%::sign::north::x}
    set {_sy} to {arrest::jail::%{_id}%::sign::north::y}
    set {_sz} to {arrest::jail::%{_id}%::sign::north::z}

    set block at location({_sx}, {_sy}, {_sz}, {_world}) to air


    set {_sx} to {arrest::jail::%{_id}%::sign::south::x}
    set {_sy} to {arrest::jail::%{_id}%::sign::south::y}
    set {_sz} to {arrest::jail::%{_id}%::sign::south::z}

    set block at location({_sx}, {_sy}, {_sz}, {_world}) to air


    set {_sx} to {arrest::jail::%{_id}%::sign::west::x}
    set {_sy} to {arrest::jail::%{_id}%::sign::west::y}
    set {_sz} to {arrest::jail::%{_id}%::sign::west::z}

    set block at location({_sx}, {_sy}, {_sz}, {_world}) to air


    set {_sx} to {arrest::jail::%{_id}%::sign::east::x}
    set {_sy} to {arrest::jail::%{_id}%::sign::east::y}
    set {_sz} to {arrest::jail::%{_id}%::sign::east::z}

    set block at location({_sx}, {_sy}, {_sz}, {_world}) to air

    # --------------------------------------------------------
    # 牢屋撤去
    # --------------------------------------------------------

    set blocks within location({_x1}, {_floor}, {_z1}, {_world}) and location({_x2}, {_ceiling}, {_z2}, {_world}) to air

    # --------------------------------------------------------
    # 5x5の床だけ残す
    # --------------------------------------------------------

    set blocks within location({_x1}, {_floor}, {_z1}, {_world}) and location({_x2}, {_floor}, {_z2}, {_world}) to cobblestone

    # --------------------------------------------------------
    # プレイヤーの収監状態を解除
    # --------------------------------------------------------

    delete {arrest::player::%{_uuid}%::jail}

    # --------------------------------------------------------
    # 牢屋を無効化
    # --------------------------------------------------------

    set {arrest::jail::%{_id}%::active} to false

    # --------------------------------------------------------
    # プレイヤーを牢屋から出す
    # --------------------------------------------------------

    if {_p} is set:
        if {_p} is online:
            teleport {_p} to location({_x} + 0.5, {_floor} + 1, {_z} + 3.5, {_world})

            send "&a&l[ARREST] &f釈放されました。" to {_p}

    # --------------------------------------------------------
    # メッセージ
    # --------------------------------------------------------

    broadcast "&a&l[ARREST] &f牢屋ID %{_id}% の収監が終了しました。"
```
