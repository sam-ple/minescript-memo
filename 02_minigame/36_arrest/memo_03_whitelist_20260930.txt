============================================================
Minecraft Paper 26.2
ホワイトリスト設定方法
============================================================


[1] ホワイトリストをONにする
============================================================

サーバーコンソールで：

whitelist on

または

whitelist true

基本的には「whitelist on」でOK。


============================================================
[2] プレイヤーを登録する
============================================================

例えば「crocadooo」を登録する場合：

whitelist add crocadooo


複数人いる場合は、それぞれ追加する。

whitelist add player1
whitelist add player2
whitelist add player3


============================================================
[3] 登録されているプレイヤーを確認する
============================================================

whitelist list


登録されているプレイヤーの一覧を確認できる。


============================================================
[4] プレイヤーを削除する
============================================================

例えば「player1」を削除する場合：

whitelist remove player1


============================================================
[5] ホワイトリストをOFFにする
============================================================

一時的に全員参加可能にする場合：

whitelist off


============================================================
[6] server.propertiesで設定する場合
============================================================

server.properties に以下を設定：

white-list=true


============================================================
[7] 現在のおすすめ設定方法
============================================================

サーバーコンソールから以下の順番で設定する。

whitelist on
whitelist add crocadooo


その後、登録状況を確認：

whitelist list


これで、ホワイトリストに登録されていないプレイヤーは
サーバーに参加できなくなる。


============================================================
[8] ARREST GAMEで使用する場合
============================================================

例えば、自分だけでテストする場合：

whitelist on
whitelist add crocadooo


友達を追加する場合：

whitelist add 友達のMinecraftID


友達を削除する場合：

whitelist remove 友達のMinecraftID


============================================================
[9] 一時的に誰でも参加できるようにする場合
============================================================

whitelist off


再びホワイトリストを有効にする場合：

whitelist on


============================================================
★ 基本コマンドまとめ
============================================================

ON：

whitelist on


OFF：

whitelist off


プレイヤー追加：

whitelist add プレイヤー名


プレイヤー削除：

whitelist remove プレイヤー名


登録者確認：

whitelist list
