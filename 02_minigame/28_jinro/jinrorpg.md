# 人狼RPG

## ルール説明
- 人狼RPGは村人・人狼・共犯者・吸血鬼の4役職に別れて戦うゲームです。
- 村人は人狼を全滅させれば勝利、
- 人狼は村人を全滅させれば勝利で、人狼同士は互いを認識できます。
- 共犯者は人狼陣営ですが、誰が人狼か分かりません。
- 吸血鬼は村人か人狼が全滅したときに生存していたら単独勝利です。また、夜の間は聖なる十字架を除き無敵です。
- このゲームは昼のターンと夜のターンがあります。
- 夜のターンはミュート/発言不可です。また、夜に出現するスケルトンを倒すとエメラルドを獲得できます。
- 昼になるとスケルトンが全て死亡し、ミュート解除/発言可能になります。
- ショップ(村人)は各所に有り、アイテムが購入できます。
- 様々なアイテムを使って敵陣営を暴き、勝利を目指しましょう。

## モブ

### スケルトン
スケルトンとは、人狼RPGに出てくるmobである。
人狼RPGにおいて唯一の敵対mob。通常のマインクラフトでは弓を持った姿が一般的だが、人狼RPGでは素手で襲いかかってくる。通称は「スケ」。
倒すと1/2の確率で、人狼RPGにおける通貨であるエメラルドを落とす。又、スケルトンに近付くと殴られてダメージを受ける（最悪の場合スケ死に繋がる）。そのためプレイヤーは、スケルトンの攻撃による体力の減少に注意しながら、スケルトンを狩らなければならない。

スケルトンは夜の時間になるとステージの様々な所にスポーンし、倒されずに残っていたスケルトンは昼になった瞬間全て消滅する（この時エメラルドは落とさない）。
そのため、人狼RPGにおいて夜の時間のプレイヤーは基本的にスケルトンを倒して過ごす事となる。

生存者の多い序盤のうちは、他の参加者と狩り場が被って先にスケルトンを倒されたりすることもある。マップによってはスケルトンの湧きが良いスポットも存在する。
人が減ってくると相対的に一人あたり倒せるスケルトンの数が増えるため装備を揃えやすくなるが、大量のスケルトンに囲まれスケ死する危険性も増す。

夜に他のプレイヤーを倒そうとすると、スケルトンにターゲットを吸われてアイテムを無駄にしてしまうという事故もあったりする。また、スケルトンが倒された時のエフェクトをプレイヤーが倒されたと見間違えることもある。

たまに高い所や狭い所など手の届きにくい場所にスポーンしてプレイヤーを困らせるスケルトンもいる。

和風旅館編から東京駅編までの間は、スケルトンを一発で倒せるスケ狩り剣が存在した。
海鳴村編では、第二の敵対mobであるウィザースケルトンが登場した。
スケルトンの耐久値
スケルトンの耐久は鈍器で4発だったのだが、城下町編以降パンチ2発(ダメージの与え具合によっては3発)になった。そのかわりスケルトンの攻撃力が2倍になった。

また、忘年会編ではハンデというシステムが追加。通常はパンチ2発のままだが、特定のプレイヤーだけ試合前にパンチの回数を増やすことができるようになった。

### ウィザースケルトン

ウィザースケルトンとは、人狼RPGに出てくるmobである。
海鳴村編で導入された人狼RPGの要素の一つ。通称は「ウィザスケ」など。
スケルトンと同じく骨で出来ていて、スケルトンと異なり黒色の骨で出来ている。通常のマインクラフトでは石の剣を持った姿が一般的だが、人狼RPGでは素手で襲いかかってくる。また、本来はウィザースケルトンに殴られると、体力が段々減っていく「衰弱」状態になるが、人狼RPGではそんなことはない。

スケルトンに混じって5％の確率で登場し、倒すとランダムにアイテムを落とす。スケルトンと同じく近付くと殴られてスケルトンの2倍のダメージを受ける。
このアイテムは、人狼の斧や共犯者の目などを除いた誰でも購入できるアイテムに限られる。

夜の時間になるとステージの各所に沸き、昼になった瞬間、倒されずに残っていたウィザースケルトンは全て消滅する。(この時アイテムは落とさない。)

スケルトンは2発殴ると倒せるが、ウィザースケルトンはスケルトンよりも耐久度が高く、6発殴らなければ倒せない。4発ハンデの場合は1人では12発殴る必要がある。通常のスケルトンよりも倒しづらいため、スケ死しそうなときは離れるのも手。

ほぼ全てのアイテムは、エメラルド2個分以上の価値があるため、見かけたら優先的に倒したいところ。いわゆるボーナスキャラである。
シャークん曰く、ウィザースケルトン1体でエメラルド5個分の期待値があるそう。

一部を除いた全てのアイテムがランダムにドロップするため、普段その役職があまり購入しないアイテムを手にする機会となる。そのため、今までの人狼RPGの価値観(騎士の加護を持っているから白っぽい、天啓の呪符を持っているから黒っぽいなど)がそのまま通用しなくなる。

クリスマスケーキ編ではウィザースケルトンがいなくなった代わりにプレゼントが導入されているが、こちらは役職限定のアイテムも手に入れることができる。

Minecraft Java / Paper / Skriptで「人狼RPG」を作成する。

まずは最小構成で実装し、動作確認後に要素を追加する。
複雑な機能は最初から入れない。

【基本】
・アドベンチャーモードでロビー待機
・Minecraftの時間は常に昼固定
・ステージ内ではブロックを壊せない
・複数ゲームを繰り返しプレイできる

【コマンド】
/jinro set
・看板登録モードON/OFF
・登録モード中にプレイヤーが看板を右クリックすると参加登録
・看板の名前はプレイヤー名から自動記入
・看板の上にプレイヤーヘッドを設置
・1人1看板
・既に登録済みのプレイヤーが別の看板をクリックした場合は登録先を変更できるようにする

/jinro unset
・看板登録解除モード
・看板を右クリックして登録解除
・プレイヤーヘッドを削除
・看板を未登録状態に戻す

/jinro start
・登録済みプレイヤーでゲーム開始
・毎ゲーム開始時に役職を再抽選
・石ボタンでのゲーム開始も実装する
・ゲーム開始時に石ボタンを消す
・全参加者をサバイバルモードにする

/jinro stop
・ゲームを途中終了
・スケルトンを全削除
・ゲーム状態を終了
・役職情報、生存/死亡情報をクリア
・参加登録情報は残す
・全参加者をアドベンチャーモードに戻す
・時間を昼固定
・石ボタンを復活

【役職】
最初は村人と人狼のみ。
・村人：人狼が全滅すると勝利
・人狼：村人が全滅すると勝利
・人狼同士は互いを認識できるようにする


役職人数は設定値として管理する。
例：
wolf = 1
mad = 0
vampire = 0
wolfed = 0

村人数は「参加人数 - 他役職人数」で自動決定する。

【ゲーム時間】
ゲーム開始直後：
・昼30秒

その後：
・夜2分
・昼2分
・夜2分
・昼2分
・夜2分……
・勝敗が決まるまで繰り返す

Minecraftの時間自体は動かさない。

【ボスバー】
・昼/夜それぞれの残り進行をバーだけで表示
・具体的な秒数や時間は表示しない
・昼→夜、夜→昼でバーをリセット

【昼夜切り替え】
昼開始：
・タイトル「昼になりました。」
・夜のスケルトンを全削除
・発言可能な時間

夜開始：
・タイトル「夜になりました。」
・スケルトンのスポーン開始

【スケルトン】
・夜の間だけ出現
・素手
・HP 2
・プレイヤーの素手攻撃2発で倒せる
・倒したプレイヤーを判定
・50%の確率でエメラルド1個を倒したプレイヤーに付与
・昼になったら残っているスケルトンを全削除
・最初はウィザースケルトンを実装しない
・スポーンはランダム方式を基本とする
・安全なスポーン地点の手動登録はしない
・必要ならMinecraftのspreadplayers等を利用する
・最初から100体固定でなくてもよい。夜の間に一定数を維持する方式でもよい

【ゲーム終了】
勝敗条件を満たしたらゲーム終了。
・勝者を表示
・役職を開示
・タイトル等で結果表示
・スケルトン全削除
・ボスバー削除
・全員をアドベンチャーモードへ
・時間を昼固定
・石ボタン復活
・参加登録は維持
・次回/jinro startで役職を再抽選して再スタート
