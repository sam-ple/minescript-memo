そう。**役職の人数設定は `jinro_role.sk` に入れる**のがいいです。

ただし、ここは「役職そのもの」と「ゲーム開始時の人数に応じた割り振り」を分けると後でかなり楽です。

### `jinro_role.sk` の役割

例えば最終的には、

```text
jinro_role.sk
├─ 役職の定義
│   ├─ 村人
│   ├─ 聖職者
│   ├─ 人狼
│   └─ 吸血鬼
│
├─ 各役職の人数設定
│   ├─ 村人 4
│   ├─ 聖職者 1
│   ├─ 人狼 2
│   └─ 吸血鬼 1
│
├─ ゲーム開始時の役職抽選
│
├─ プレイヤーへの役職保存
│
└─ 本人だけに役職通知
```

という形です。

## 人数設定は変数にする

例えば、

```skript
# ============================================================
# Jinro RPG - Role Settings
# ============================================================

# 役職人数

set {jinro.role.count.villager} to 4
set {jinro.role.count.blessed} to 1
set {jinro.role.count.wolf} to 2
set {jinro.role.count.vampire} to 1
```

とすれば、

**8人ゲーム**

```text
村人       4
聖職者     1
人狼       2
吸血鬼     1
──────────
合計       8
```

になります。

ただ、これを毎回 `/jinro` コマンドで設定するより、最初は**設定コマンドを作っておく**のがおすすめです。

例えば、

```text
/jinrorole set villager 4
/jinrorole set blessed 1
/jinrorole set wolf 2
/jinrorole set vampire 1
```

みたいにします。

そして、

```text
/jinrorole info
```

で

```text
[Jinro RPG Role]
村人       : 4
聖職者     : 1
人狼       : 2
吸血鬼     : 1
────────────
合計       : 8
```

と確認できます。

---

## さらに重要なのが「ゲーム人数」

ここは `jinro_core.sk` と連携します。

例えば参加者が10人なのに、

```text
村人 4
聖職者 1
人狼 2
吸血鬼 1
```

だと合計8人なので、**2人足りません**。

逆に、

```text
村人 6
聖職者 1
人狼 3
吸血鬼 1
```

なら合計11人なので、10人では開始できません。

だからゲーム開始時に、

```text
参加人数
    ↓
役職人数合計
    ↓
一致？
    ↓
YES → 役職抽選して開始
NO  → 開始しない
```

というチェックを `jinro_core.sk` から `jinro_role.sk` に確認させます。
